How it works

Tidy in three steps

No setup to learn. Run it once to see your desktop sorted, then adjust the rules if you like.

  1. Install and open

    Run DeskOrgSetup.exe, then open DeskOrg from your desktop or Start Menu. The Control Center opens.

  2. Organize Now

    Go to Organize and press Organize Now. Your desktop is sorted into category folders using your rules.

  3. Automate (optional)

    In Smart Automation, turn on the watcher so new files are filed automatically from now on.

FAQ

Questions, answered

Is DeskOrg free?

Yes. DeskOrg is free and released under the MIT licence. There are no ads, accounts or trials.

Does DeskOrg upload my files?

No. Everything runs on your PC. DeskOrg only moves files between folders on your own computer.

Does it delete anything?

No. It moves files from the desktop into category folders using your rules, and protected file types are left where they are. The Activity log shows every move, so you can always find a file.

Can I change which folder a file type goes to?

Yes. Open Rules & Settings to edit categories and file types. Your rules are saved in your own Windows profile, so they survive updates and reinstalls.

Do I have to keep it running?

No. Use Organize Now whenever you like. Only if you turn on Smart Automation does a small background watcher file new items for you; you can disable it any time.

How do I uninstall it?

Open Windows Settings › Apps, find DeskOrg and choose Uninstall. Your organized folders stay on the desktop.
