Install help

Let's get DeskOrg installed

If the install was blocked or didn't finish, here are the usual reasons, each with a quick fix.

Messages Windows protected your PCSecurity promptAntivirusAdministrator permissionA file is in useStill stuck?

DeskOrg is signed with its own certificate rather than an expensive commercial one. That keeps it free, but Windows doesn't recognise the publisher yet, so it plays it safe the first time. None of the steps below are risky: you're just telling Windows you trust this app.

Most common

"Windows protected your PC" (blue box)

This is SmartScreen. It appears for any new app without a big-brand reputation.

  1. Click More info in the blue box.
  2. Click the Run anyway button that appears.
Common

A Yes/No security prompt appeared and nothing happened

That was User Account Control (UAC) asking for permission to install. If you clicked No, the install stops.

  1. Run DeskOrgSetup.exe again.
  2. When the prompt appears, click Yes.
Occasional

Your antivirus blocked or removed the installer

Some antivirus tools are cautious with brand-new, self-signed apps (a false alarm).

  1. Open your antivirus's Quarantine or Protection history.
  2. Choose Allow, Restore or Trust for DeskOrg, then run the installer again.
Occasional

"You need administrator permission"

DeskOrg installs into Program Files, which needs admin rights.

  1. Right-click DeskOrgSetup.exe › Run as administrator.
  2. Click Yes on the prompt.
Occasional

"A file is in use" or it couldn't replace files

DeskOrg is already open, or a previous copy is still running.

  1. Close DeskOrg (check the taskbar and the system tray).
  2. Run the installer again.
Last resort

Still stuck?

Restart your PC and run DeskOrgSetup.exe once more. If it still won't install, contact us and mention exactly which message you saw.
