What DeskOrg does

DeskOrg is a lightweight Windows app that sorts the files cluttering your desktop into category folders (documents, images, installers, archives and more) using rules you control. Run it whenever you like with one click, or let it file new things in the background the moment they land.

Everything happens on your own PC. DeskOrg doesn't upload, sync or share your files, and it never deletes anything: it only moves files from the desktop into folders.

Quick start

  1. Open DeskOrg. Double-click the DeskOrg icon on your desktop, or find it in the Start Menu. A short splash appears, then the Control Center opens.
  2. Go to Organize › Organize Now. Your desktop is sorted into category folders using your current rules.
  3. Optional: turn on automation. In Smart Automation, enable the watcher so new files are filed automatically from now on.
Tip: run Organize Now once to see how your desktop gets sorted, then adjust the rules before you turn on automation.

The Control Center, tab by tab

Five tabs down the left side of the window:

  • 01Overview: your home dashboard, with a welcome and the current state of your setup (rules, automation, log).
  • 02Organize: Preview first shows which files would move, without moving anything. Organize now runs the cleanup. Undo last organize puts the files from the last run back. You can also open your Windows Desktop folder or the DeskOrg application folder from here.
  • 03Smart Automation: install and enable the background watcher, check its status, disable it, or uninstall automation.
  • 04Rules & Settings: edit which file types go into which folder, open the application folder, and refresh the status on the home screen.
  • 05Activity & Logs: open the DeskOrg log to see what was moved, and confirm the organizer and automation scripts are present.

Rules and protected file types

Categories and file types are fully editable under Rules & Settings with Open rules editor: add a folder, rename it, or move an extension (for example .pdf) to a different category. The editor also lets you tidy your Downloads folder or any other folder, sort into month or year folders, choose what happens when a file with the same name is already there, and list files that must never move (for example invoice-*.pdf).

Some file types are protected: DeskOrg handles them carefully and leaves them where they are, so important files and shortcuts aren't moved unexpectedly.

Your rules are saved in your own Windows user profile, so they survive updates and reinstalls.

Smart Automation

When automation is on, a small background watcher notices new files on the desktop and files them using the same rules as Organize Now. You don't need to keep the Control Center open.

You can check its status, use Pause / resume tidying to stop it for a while, or remove it completely with Uninstall automation, all from the Smart Automation tab. DeskOrg keeps an icon near the clock; closing the window hides it there, and right-clicking the icon offers Open, Organize now, Undo, Pause and Exit. After an automatic tidy, Windows shows a small notification.

Undo and preview

Before trusting DeskOrg with a busy folder, press Preview first. Every organize is recorded, so Undo last organize puts those files back, and pressing it again goes one run further back.

History and logs

Every tidy-up is listed on the History tab with its time. Press Details to see each file and the reason it moved, Put back to return one file, or Undo to return the whole tidy-up. The full log is one click away too, so you can always find a file again.

New in version 1.2

The tabs now have plain names (Home, Tidy up now, Keep it tidy automatically, Where files go, History) and the Control Center speaks English, Hindi or Punjabi.

  • Welcome screen on first start: pick Desktop and/or Downloads, see a preview, nothing moves until you say so.
  • More rules: by file name (for example Screenshot*), by size, and for files untouched for many days. Drag files onto the rules editor to add their types; import and export your rules.
  • Quiet hours: times when DeskOrg must not tidy by itself.
  • Downloads and other folders are watched live, each with its own options.
  • Find duplicate files: identical copies are listed and only the extras you tick go to the Recycle Bin.
  • Easier to read: bigger text, high-contrast option, a progress bar, and keyboard shortcuts (F1 opens this guide).
  • Private: DeskOrg works only on your PC; it never uploads your files or their names.

Install problems?

DeskOrg's files are code-signed with its own certificate, so Windows may show a caution the first time. Click More info, then Run anyway. For every other message (security prompt, antivirus, admin rights, files in use) see the Install help page.

More step-by-step answers (finding moved files, editing rules, automation, uninstalling) are in the DeskOrg help articles. Still stuck? Contact us and tell us exactly which message you saw.
